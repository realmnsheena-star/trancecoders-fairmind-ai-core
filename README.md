# 🧠 FairMind AI — Unbiased AI Decision Maker

> Removing Bias. Ensuring Fairness. Explaining Decisions.

## 🚨 The Problem
AI systems in hiring, loans, and healthcare make biased 
decisions based on gender, age, and marital status — 
causing unfair outcomes for millions of people.

## 💡 Our Solution
FairMind AI detects and removes sensitive attributes 
before making any decision. Every outcome is fair, 
scored, and fully explained.

👉 [Try FairMind AI](#) ← paste your Lovable link

## ✨ Features
- 🔍 Bias detection & removal
- ✅ Fair merit-based scoring (5 factors)
- 📊 Score breakdown table
- 📋 Plain-English explanation
- 🎙️ Voice input on all fields
- 🔊 Text-to-speech result reading
- 🤖 AI chatbot assistant
- 📱 Fully responsive design

## 🛠️ Tech Stack
| Layer      | Technology              |
|------------|-------------------------|

| Voice      | Web Speech API          |
| Hosting    | Firebase / Render       |
| Logic      | Custom Fairness Engine  |
